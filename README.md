# The Funniest Out-of-Office

A one-line out-of-office reply, written by a small Python program to `/output/entry.txt`:

> Out of office: I have left the building, the inbox, and my will to reply. Your email will be ignored in the order received.

## Run

From the repository root:

```
python3 main.py
```

This writes the line (123 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).

## About this entry

This out-of-office reply quits in slow motion, in three stages.
First the building, which is the normal part. Then the inbox,
which is already a small rebellion. Then the will to reply,
which is the real resignation hiding inside a vacation notice.
The last clause is what makes it funny instead of merely rude:
the emails will still be ignored, but fairly, in the order
received — the sender keeps the one shred of professionalism
the office runs on, a queue, and applies it to doing nothing.
It is the fantasy every inbox dreads and every worker has
rehearsed: leaving, properly, with the paperwork in order.
